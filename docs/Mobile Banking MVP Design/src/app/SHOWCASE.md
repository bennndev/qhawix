### **Escenario 2: Transferencia Sospechosa - Protección AI**

```
1. Dashboard → Botón "Transferir"
   └─> Transfer Screen
       ├─> Jorge ingresa:
       │   Destinatario: "Cuenta no registrada"
       │   Monto: S/ 5,850 (>S/ 2,000 threshold)
       │   Concepto: "Pago urgente"
       └─> Toca "Confirmar"

2. Sistema Detecta Anomalía
   ├─> AURA se vuelve naranja (alert mode)
   ├─> Console: "🚨 Suspicious transaction detected"
   └─> Inicia Fase 1: Voice Verification

3. Fase 1 - Voz
   ├─> Pantalla con forma de onda animada
   ├─> AURA pregunta (voz sintética simulada):
   │   "Hola Jorge, detecté una transferencia de
   │    S/ 5,850 a una cuenta nueva. ¿Podrías
   │    confirmar si la aprobaste?"
   ├─> Usuario responde (simulado)
   └─> IA detecta: "Estrés en la voz" → Fase 2

4. Fase 2 - Gesto
   ├─> Cámara se activa (overlay)
   ├─> Instrucción: "Gira suavemente el teléfono
   │                  y sonríe para la cámara"
   ├─> Análisis de micro-expresiones
   └─> Resultado: "Patrón anormal" → Fase 3

5. Fase 3 - Dual Outcome
   ├─> Vista Usuario (izquierda):
   │   └─> "✅ Transferencia Exitosa
   │        Recibirás confirmación por SMS"
   └─> Vista Operador (derecha - modo demo):
       └─> "🚨 ALERTA DE SEGURIDAD
            Usuario: Jorge Pino
            Voz: Estrés detectado
            Gesto: Patrón anormal
            Acción: BLOQUEADA
            Operadores notificados"

6. Return to Dashboard
   └─> Saldo sin cambios (transferencia bloqueada)
   └─> AURA vuelve a modo stealth (10% opacidad)
```
